# ICU 患者 28 天死亡风险预测实验计划：重构版

## 一、研究主题

本研究基于 MIMIC-IV 衍生分析数据集，使用 ICU 入科后前 24 小时内可获得的结构化临床变量，预测 ICU 患者入科后 28 天死亡风险。

重构后的研究重点不再是单纯比较多个机器学习模型，而是把当前完整实验作为 baseline，进一步围绕以下问题展开：

1. 最高 AUROC 模型是否也是概率最可靠的模型；
2. ICU 数据中的缺失模式是否能提供额外预测信息；
3. 早期生命体征、实验室指标和 24 小时动态摘要分别贡献多少；
4. SHAP 解释结果是否在不同模型、重采样和亚组中稳定；
5. 实验流程是否符合临床预测模型透明报告要求。

## 二、文献对照与研究空白

| 文献方向 | 已有研究特点 | 本研究的改进方向 |
| --- | --- | --- |
| APACHE II、SAPS II、SOFA 等传统 ICU 评分 | 固定变量、固定权重，解释性强，但难以充分利用高维 EHR 变量和非线性关系。 | 保留传统评分思想作为临床参照，强调模型不能只追求黑箱性能。 |
| MIMIC 临床机器学习 benchmark | 强调标准化任务、时间窗、可复现处理和公开基线。 | 明确预测时点为入 ICU 后 24 小时，后续加入特征组和时间窗消融。 |
| MIMIC/eICU 28 天死亡预测研究 | 常见做法包括 XGBoost/LightGBM、SHAP、内部或外部验证。 | 不把 LightGBM/SHAP 本身作为创新，而是关注校准、缺失机制和解释稳定性。 |
| TRIPOD/TRIPOD+AI | 强调预测对象、结局、预测时点、缺失处理、模型规格和验证流程的透明报告。 | 按临床预测模型报告规范重构实验方案和论文方法部分。 |

## 三、研究对象

- 数据来源：`data/processed/ch3_analysis_dataset.parquet`
- 纳入标准：
  - ICU 住院记录可用；
  - ICU 住院时长不少于 24 小时；
  - `death_28d` 结局可用。
- 当前 baseline 运行结果：
  - 总样本量：51,838
  - 28 天死亡例数：6,935
  - 事件率：13.38%
  - 数值特征：71 个
  - 分类特征：3 个

正式重跑时建议额外保存 subject/stay 唯一性核验表，作为信息泄漏排查证据。

## 四、结局定义

主要结局为 ICU 入科后 28 天内死亡：

```text
death_28d = 1 表示 28 天内死亡
death_28d = 0 表示 28 天内未死亡
```

预测时点为 ICU 入科后 24 小时。所有预测变量应在该时点之前可获得，避免使用结局后信息。

## 五、预测变量

当前 baseline 使用 ICU 入科后前 24 小时内可获得的结构化变量：

- 人口学变量：年龄、性别、种族分组；
- ICU 入科单元：first ICU care unit；
- 生命体征：心率、呼吸频率、SpO2、收缩压、舒张压、平均动脉压、体温；
- 实验室指标：白细胞、血红蛋白、血小板、电解质、肾功能、血糖、阴离子间隙、凝血指标等。

后续消融实验将按以下特征组重新训练和比较：

| 实验组 | 特征范围 | 目的 |
| --- | --- | --- |
| Demographics only | 年龄、性别、种族、ICU 单元 | 建立最弱临床基线 |
| Vitals only | HR、RR、SpO2、BP、体温 | 评估床旁监测变量价值 |
| Labs only | 血常规、电解质、肾功能、凝血等 | 评估实验室指标价值 |
| First value only | 仅 first 特征 | 评估入科初始状态 |
| First + summary | first + mean/min/max | 评估 24 小时动态摘要增益 |
| Full model | 当前完整特征 | 作为主模型 |

如果原始数据支持 6 小时、12 小时、24 小时重新聚合，则进一步做时间窗对照，评价更早风险分层的可行性。

## 六、建模方案

### 6.1 当前 baseline

- 数据划分：分层训练集/测试集划分，测试集比例 20%；
- 交叉验证：训练集内 5 折分层交叉验证；
- 缺失值处理：数值变量使用中位数填补，分类变量使用众数填补；
- 变量处理：数值变量标准化，分类变量 one-hot 编码；
- 候选模型：LogisticRegression、DecisionTree、RandomForest、ExtraTrees、HistGradientBoosting、XGBoost、LightGBM、CatBoost；
- 阈值策略：在训练集上选择 F1 最优阈值，再用于测试集评价；
- 不确定性：测试集 bootstrap 95% 置信区间；
- 解释：对最佳模型计算 SHAP。

### 6.2 建议重构后的模型选择

当前文本中“以测试集 AUROC 选择最佳模型”的表述容易带来方法学质疑。建议改为：

1. 在训练集内通过交叉验证选择模型和超参数；
2. 如需校准，从训练集中划分验证集或使用交叉验证校准；
3. 独立测试集只用于最终一次报告；
4. 同时报告所有候选模型的测试表现，但主结论基于预先设定的选择规则。

建议预先设定两类主模型：

- **区分度主模型**：以训练集交叉验证 AUROC/AUPRC 综合表现选择；
- **临床概率主模型**：以校准后 Brier score 和校准曲线表现选择。

这样可以避免把“AUROC 最高”直接等同于“最适合临床风险概率解释”。

## 七、新增实验模块

### 模块 1：校准与阈值实验

对表现靠前的模型进行：

1. 未校准概率；
2. Platt scaling；
3. Isotonic regression。

比较 AUROC、AUPRC、Brier score、校准曲线、Precision、Recall、F1，以及低/中/高风险分层中的真实死亡率。

### 模块 2：缺失机制实验

比较三种数据处理策略：

1. 中位数/众数填补；
2. 填补 + 数值变量 missing indicator；
3. 填补 + 特征组缺失负担，例如生命体征、血常规、电解质、肾功能、凝血指标缺失比例。

该模块用于回答：ICU 中“是否检测某项指标”是否本身携带病情严重程度或临床关注点信息。

### 模块 3：特征组与时间窗消融

按人口学、生命体征、实验室指标、first 测量、24 小时摘要等特征组重训模型，比较性能变化。若数据支持，则进一步比较 6h、12h、24h 时间窗。

该模块用于回答：模型预测能力主要来自哪些早期临床信息，以及是否能在更早时点完成风险分层。

### 模块 4：解释稳定性实验

对 LightGBM、XGBoost、HistGradientBoosting 等表现靠前模型分别计算 SHAP，并通过 bootstrap 或重复抽样统计 Top 特征出现频率。

报告时区分：

- 稳定出现的关键特征；
- 只在单次模型或单次抽样中出现的特征；
- 不同亚组中解释结果可能存在的差异。

## 八、评价指标

| 指标类型 | 指标 | 作用 |
| --- | --- | --- |
| 区分能力 | AUROC、AUPRC | 评价风险排序和阳性事件识别能力 |
| 阈值后分类 | Accuracy、Precision、Recall、F1、混淆矩阵 | 评价给定阈值下的分类表现 |
| 概率可靠性 | Brier score、校准曲线、校准截距/斜率 | 评价预测概率能否解释为真实风险 |
| 不确定性 | Bootstrap 95% CI | 避免只报告单次点估计 |
| 可解释性 | SHAP 排名、SHAP 稳定性 | 分析模型依赖哪些变量以及解释是否稳定 |
| 临床分层 | 风险分层死亡率、可选 DCA | 评价模型在辅助分层中的意义 |

## 九、当前 baseline 运行结果

当前完整实验中，LightGBM 在测试集 AUROC 上排名第一：

- 测试集 AUROC：0.874
- 测试集 AUPRC：0.556
- Accuracy：0.872
- Precision：0.518
- Recall：0.559
- F1：0.538
- Brier score：0.132

Bootstrap 95% 置信区间：

- AUROC：0.865-0.883
- AUPRC：0.527-0.582
- Accuracy：0.865-0.878
- Precision：0.491-0.543
- Recall：0.535-0.584
- F1：0.516-0.560
- Brier score：0.128-0.135

LightGBM 混淆矩阵：

- TN：8,232
- FP：749
- FN：611
- TP：776

需要强调：LightGBM 的 AUROC 最高，但 HistGradientBoosting 和 XGBoost 的 Brier score 约为 0.083，明显低于 LightGBM。因此，后续重构实验应重点比较“区分度最佳模型”和“概率校准最佳模型”的差异。

## 十、医学解释方向

当前 SHAP 结果中，贡献较高的变量包括年龄、CVICU 入科、BUN、呼吸频率、氯离子、阴离子间隙和 SpO2 等。这些变量大体对应基础脆弱性、呼吸状态、肾功能、代谢状态和收治单元差异，具有一定临床可解释性。

但 SHAP 解释的是模型如何使用变量，不代表这些变量对死亡结局具有因果作用。后续解释稳定性实验将进一步判断这些特征是否在不同模型、重采样和亚组中持续出现。

## 十一、预期创新表述

答辩和论文中建议这样表述：

> ICU 死亡风险预测已有很多类似研究，因此本研究不把创新点放在单纯提出新模型上。我们的重点是把一个常规 MIMIC-IV 机器学习预测实验，重构为面向临床风险分层的规范化评估流程：同时关注区分度、类别不平衡下的阳性识别能力、概率校准、缺失机制、特征组贡献和解释稳定性。相比只报告 AUROC 和单次 SHAP 排名的研究，本研究更强调模型是否可靠、哪些数据处理环节带来增益，以及解释结果是否稳定。
