# ICU 28 天死亡风险预测研究：实验方案重构、文献对照与创新点

> 目的：回应“类似研究已经很多，需要突出创新点”的意见。本文先把本研究放回已有文献脉络中，再明确哪些内容是当前已有结果，哪些是建议新增实验。后续若老师认可，可据此同步重写 README、论文初稿和 PPT。

## 一、现有方案的主要问题

当前项目已经完成了一个完整的 ICU 28 天死亡风险预测流程：纳入 51,838 条 ICU 记录，死亡事件 6,935 例，事件率 13.38%；使用入 ICU 后前 24 小时结构化变量，比较 Logistic Regression、Decision Tree、RandomForest、ExtraTrees、HistGradientBoosting、XGBoost、LightGBM、CatBoost 等模型，并用 ROC、PR、校准曲线、Bootstrap CI 和 SHAP 解释模型。

但从“创新性”角度看，现有叙事容易被理解为：

1. 使用公开 MIMIC-IV 数据集做 ICU 死亡预测；
2. 比较多个常见机器学习模型；
3. 选择 AUROC 最高模型；
4. 用 SHAP 解释特征重要性。

这条路线在 ICU 预后预测研究中已经非常常见。真正需要重构的不是简单再换一个模型，而是把研究目标从“做一个表现不错的模型”改为“在已有 ICU 死亡预测研究的不足上做规范化、稳健性和可解释性增强”。

## 二、参考文献与本研究可借鉴之处

| 文献方向 | 代表文献 | 已有研究做了什么 | 对本研究的启发 |
| --- | --- | --- | --- |
| 公开 ICU 数据库 | Johnson et al., MIMIC-IV, PhysioNet / Scientific Data | MIMIC-IV 提供 2008-2019 年 BIDMC 真实世界去标识化 EHR 数据，支持 ICU 预后建模和可复现研究。 | 数据来源本身不是创新点；创新应落在队列定义、特征处理、评估设计和可复现流程。 |
| 传统 ICU 评分 | APACHE II、SAPS II、SOFA | 传统评分用固定生理变量和固定权重描述病情严重程度或预测死亡风险，解释性强但变量维度和非线性表达有限。 | 本研究可把传统评分/临床变量子集作为基线，而不是只比较机器学习模型。 |
| MIMIC 临床机器学习 benchmark | Harutyunyan et al., Scientific Data 2019 | 基于 MIMIC-III 建立 ICU benchmark，强调标准任务、时间窗、可复现处理和公开基线。 | 本研究应明确 first 24h 的时间窗合理性，并做时间窗或特征组消融，而不只做单一 24h 模型。 |
| ICU 28 天死亡可解释模型 | 例如 sepsis-induced coagulopathy 28-day mortality 研究 | 常见做法是 MIMIC-III/MIMIC-IV/eICU 队列、XGBoost/LightGBM、SHAP、内外部验证。 | 如果只做 LightGBM + SHAP，很难构成创新；应增加校准、泛化、缺失机制、解释稳定性等实验。 |
| ICU AI 外部验证综述 | External validation of AI-based scoring systems in the ICU, 2024 | ICU AI 模型常有内部表现好、外部验证不足的问题；MIMIC 和 eICU 是常见开发/验证数据源。 | 若暂时不能外部验证，至少要做时间切分、亚组验证或 bootstrap/交叉验证稳定性，并把外部验证作为正式局限。 |
| 临床预测模型报告规范 | TRIPOD 2015；TRIPOD+AI 2024 | 强调透明报告数据来源、预测对象、结局、缺失处理、模型选择、验证和完整模型规格。 | 本研究可按 TRIPOD+AI 重构实验方案，突出“规范化预测模型研究”而不是泛泛算法比较。 |
| 模型与解释方法 | LightGBM；SHAP | LightGBM 适合结构化表格数据；SHAP 可解释模型输出，但不能证明因果关系。 | 创新不应写成“用了 LightGBM/SHAP”，而应写成“比较解释结果在特征组、亚组、时间窗中的稳定性”。 |

## 三、建议重构后的研究定位

建议把题目从：

> 基于 MIMIC-IV 的 ICU 患者 28 天死亡风险预测研究

调整为：

> 基于 MIMIC-IV 早期结构化数据的 ICU 28 天死亡风险预测：面向校准、缺失机制与解释稳定性的可复现实验研究

这个定位有三个好处：

1. 承认“ICU 死亡预测”不是新问题，避免硬说首创；
2. 把创新点放在实验设计质量上，而不是堆模型；
3. 能自然回答老师关心的“相比参考文献，创新在哪里”。

## 四、重构后的核心创新点

### 创新点 1：从“模型性能比较”转为“临床可用性导向的评估框架”

已有很多研究主要报告 AUROC，并选择 AUROC 最高的模型。但 ICU 风险模型如果要辅助分层，光有区分能力不够，还要关注：

- AUPRC：死亡事件率只有 13.38%，类别不平衡下 PR 曲线比单看 AUROC 更贴近阳性识别能力；
- Brier score 和校准曲线：当前结果显示 LightGBM 的 AUROC 最高，但 Brier score 为 0.132，而 HistGradientBoosting 和 XGBoost 的 Brier score 约为 0.083，提示“最高 AUROC 模型未必是概率最可靠模型”；
- 阈值策略：当前已经使用训练集 F1 最优阈值，后续可进一步比较固定阈值、Youden 阈值、F1 阈值和高召回阈值；
- 决策价值：可新增 Decision Curve Analysis 或按风险分层统计死亡率，说明模型在临床分层中的实际意义。

可写成创新表达：

> 与仅以 AUROC 选择模型的研究不同，本研究将 AUROC、AUPRC、Brier score、校准曲线和阈值后分类指标共同纳入评价，重点分析“排序能力”和“概率可靠性”之间的差异，使模型选择更接近 ICU 风险分层场景。

### 创新点 2：把缺失机制纳入特征工程，而不是只做中位数填补

当前方案对数值变量用中位数填补，对分类变量用众数填补。这个处理简单可复现，但没有利用 ICU 数据中“是否被检测”本身可能携带的临床信息。

已有缺失概况显示，PTT 相关变量缺失率约 15.31%，INR 相关变量缺失率约 14.70%，温度、MAP、血常规等也存在不同程度缺失。ICU 中某项化验是否被频繁检测，可能反映病情严重程度、出血/凝血风险或治疗关注点。

建议新增三组对照：

1. 基础填补模型：当前中位数/众数填补；
2. 缺失指示器模型：为数值变量增加 `is_missing` 特征；
3. 缺失负担模型：按生命体征、血常规、电解质、肾功能、凝血等特征组统计缺失比例。

可写成创新表达：

> 与将缺失值仅视为技术问题的研究不同，本研究将“缺失模式”作为 ICU 早期监测强度和临床关注点的代理信息，比较传统填补、缺失指示器和特征组缺失负担对 28 天死亡预测的增益。

### 创新点 3：做特征组和时间窗消融，回答“哪些早期信息真正有价值”

当前使用 first、mean、min、max 等 24 小时汇总特征，但没有回答：

- 只用首次测量值是否已经足够？
- mean/min/max 这类 24 小时动态摘要是否带来增益？
- 生命体征、实验室指标、人口学、ICU 单元分别贡献多少？
- 更早时间窗，如 6h、12h，是否能在更早时点达到可接受性能？

建议新增消融矩阵：

| 实验组 | 特征范围 | 目的 |
| --- | --- | --- |
| Demographics only | 年龄、性别、种族、ICU 单元 | 建立最弱临床基线 |
| Vitals only | HR、RR、SpO2、BP、体温 | 评估床旁监测变量价值 |
| Labs only | 血常规、电解质、肾功能、凝血等 | 评估实验室指标价值 |
| First value only | 仅 first 特征 | 评估入科初始状态 |
| First + summary | first + mean/min/max | 评估 24 小时动态摘要增益 |
| Full model | 当前完整特征 | 作为主模型 |

如果原始数据支持 6h/12h/24h 重新构建，则进一步新增时间窗实验：

| 时间窗 | 临床意义 |
| --- | --- |
| 6h | 入 ICU 早期快速分层 |
| 12h | 半日内评估 |
| 24h | 当前主模型，信息更充分 |

可写成创新表达：

> 本研究不只报告一个 24 小时全量模型，而是通过特征组和时间窗消融，量化早期生命体征、实验室检查和 24 小时动态摘要对死亡风险预测的边际贡献，从而回答模型性能来自哪里。

### 创新点 4：解释稳定性，而不是单次 SHAP 排名

当前 SHAP 结果显示，年龄、CVICU、BUN、呼吸频率、氯离子、阴离子间隙、SpO2 等变量贡献较高。但单次 SHAP 排名容易受到模型、样本抽样和特征相关性的影响。

建议新增：

1. 不同模型的解释对照：LightGBM、XGBoost、HistGradientBoosting 的 Top 特征是否一致；
2. Bootstrap SHAP 稳定性：重复抽样计算 Top 10 特征出现频率；
3. 亚组解释：按年龄组、ICU 单元、性别等比较 Top 特征；
4. 解释边界：明确 SHAP 是模型归因，不是因果证据。

可写成创新表达：

> 与只展示一次 SHAP 图的研究不同，本研究关注解释结果的稳定性，评估关键特征在不同模型、重采样和亚组中的一致性，避免把偶然的单次排序误读为稳定临床规律。

### 创新点 5：按 TRIPOD+AI 思路重构报告流程

建议把论文和 README 的方法部分改为以下逻辑：

1. 明确预测对象：ICU 入科后至少 24 小时且 28 天死亡结局明确的患者/住次；
2. 明确预测时点：ICU 入科后 24 小时；
3. 明确预测时间范围：入科后 28 天；
4. 明确预测变量是否可在预测时点之前获得；
5. 明确缺失处理、类别不平衡处理、模型选择流程；
6. 明确验证方式：交叉验证选模，独立测试集最终评估；
7. 明确完整模型规格、随机种子、代码和输出文件；
8. 明确模型解释和临床使用边界。

可写成创新表达：

> 本研究按 TRIPOD+AI 对临床预测模型的透明报告要求重构实验流程，重点保证预测时点、变量可得性、模型选择、最终验证和解释边界清晰，从而提升研究的可复现性和方法学规范性。

## 五、建议的新实验方案

### 阶段 0：保留现有实验作为 baseline

目的：不推翻已有工作，而是把它定义为 baseline。

- 队列：当前 51,838 条记录；
- 特征：前 24 小时人口学、生命体征、实验室指标、ICU 单元；
- 模型：当前 8 类模型；
- 结果：LightGBM AUROC 0.874，AUPRC 0.556，Brier 0.132。

注意：当前数据集中 `subject_id` 与记录数一致，说明已没有同一 subject 的重复 ICU 记录；正式重跑时建议保存一张 subject/stay 唯一性核验表，作为数据泄漏排查证据。

### 阶段 1：重做模型选择流程

当前文本提到“以测试集 AUROC 选择最佳模型”，这在方法学上容易被质疑。建议改为：

1. 训练集内交叉验证选择模型和超参数；
2. 可选：从训练集中再划分 validation set 做校准；
3. 独立测试集只用于最终一次评估；
4. 报告所有候选模型的测试表现，但主结论基于预先设定的选择规则。

主指标建议：

- primary：AUROC + AUPRC；
- clinical reliability：Brier score + calibration slope/intercept + calibration curve；
- threshold metrics：precision、recall、F1、confusion matrix；
- uncertainty：bootstrap 95% CI。

### 阶段 2：新增消融实验

至少建议完成以下 6 组：

1. 人口学 + ICU 单元；
2. 生命体征 only；
3. 实验室指标 only；
4. 首次测量值 only；
5. first + mean；
6. first + mean + min/max，即当前完整特征。

如果时间有限，优先做 1、2、3、6，可以最快回答“模型到底依赖哪类信息”。

### 阶段 3：新增缺失机制实验

建议完成：

1. 当前中位数/众数填补；
2. 中位数/众数填补 + missing indicator；
3. 中位数/众数填补 + group-level missing burden。

报告：

- 性能是否提升；
- Top 缺失指示变量是否与凝血、血气/代谢、血流动力学等临床关注点有关；
- 如果缺失特征过强，需要讨论其可能反映医疗流程差异，而非病理机制。

### 阶段 4：新增校准实验

建议对表现靠前的模型做：

1. 未校准概率；
2. Platt scaling；
3. Isotonic regression。

比较：

- AUROC 是否基本不变；
- Brier score 是否下降；
- 校准曲线是否更接近对角线；
- 风险分层组，例如低风险、中风险、高风险，对应真实死亡率是否单调上升。

### 阶段 5：新增解释稳定性实验

建议：

1. 对 LightGBM、XGBoost、HistGradientBoosting 分别输出 SHAP Top 20；
2. 计算 Top 10 特征在 bootstrap 重采样中的出现频率；
3. 按年龄组或 ICU 单元输出局部亚组 SHAP；
4. 在论文中把“稳定出现的特征”与“单次出现的特征”区分开。

## 六、论文/汇报中可以这样回答“创新点在哪里”

建议答辩时不要说“我们首次使用 LightGBM/SHAP”，因为这个说法很容易被文献反驳。更稳妥的回答是：

> 老师说得对，ICU 死亡风险预测已有很多类似研究，所以我们不把创新点放在单纯提出一个新模型上。本研究的创新主要在实验设计和可解释验证上：第一，我们不只看 AUROC，而是同时评价 AUPRC、Brier score、校准曲线和阈值后指标，强调 ICU 风险分层中概率可靠性的重要性；第二，我们把临床数据缺失模式作为潜在信息纳入特征工程，而不是简单填补后忽略；第三，我们通过特征组消融和解释稳定性分析，回答模型性能主要来自哪些早期临床信息，避免只展示一次 SHAP 排名。这样，本研究相比常规 MIMIC-IV 机器学习预测研究，更关注模型的规范化评估、数据处理机制和解释结果稳定性。

## 七、建议修改后的论文结构

1. 引言
   - ICU 早期死亡风险分层的临床意义；
   - 传统评分系统的优势与限制；
   - MIMIC 数据推动可复现 ICU 机器学习研究；
   - 现有研究不足：同质化模型比较多，校准、缺失机制、消融和解释稳定性不足。

2. 相关工作
   - 传统 ICU 评分：APACHE II、SAPS II、SOFA；
   - MIMIC benchmark 与 ICU 机器学习死亡预测；
   - 可解释机器学习和 SHAP；
   - 临床预测模型报告规范：TRIPOD/TRIPOD+AI；
   - 本研究与以上工作的区别。

3. 方法
   - 数据来源与队列；
   - 预测时点和结局；
   - 特征构建；
   - 缺失机制处理；
   - 模型训练与选择；
   - 校准和阈值策略；
   - 消融与稳定性实验。

4. 结果
   - baseline 结果；
   - 消融实验；
   - 缺失机制实验；
   - 校准实验；
   - SHAP 稳定性；
   - 亚组结果。

5. 讨论
   - 与既有研究相比的主要发现；
   - 为什么最高 AUROC 不等于最佳临床概率模型；
   - 缺失模式的临床含义；
   - 解释稳定性与因果边界；
   - 局限：单中心、回顾性、外部验证不足等。
